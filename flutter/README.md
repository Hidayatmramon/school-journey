# Flutter

| Folder | What it covers |
|---|---|
| `kasirku` | A cashier UI: product list, add and remove items, and a running total of items and price |
| `learning-day1` | My first Flutter app (starter project) |
| `learning-day2` | An article list UI built from widgets (home, news, and popular sections) |

## Running the examples

Requirements: the Flutter SDK.

The generated platform folders (`android`, `ios`, `web`, and so on) are not committed. Regenerate them inside a project folder, then run it:

```bash
cd flutter/kasirku
flutter create .
flutter pub get
flutter run
```
