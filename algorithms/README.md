# Algorithms

Flowchart and logic exercises converted into code. Most problems are solved in C++ (`C++/`) and PHP (`PHP/`) so I could compare how the same logic looks in different languages. For example, `no2` finds the largest of three numbers. The `Python/` folder holds a later set of exercises.

| Folder | Files |
|---|---|
| `C++/` | `no2` to `no8`, plus `versi-1.cpp` |
| `PHP/` | `no2` to `no8`, `no11`, and `no12` |
| `Python/` | `diskonbuku.py` (book discount), `kabisat.py` (leap years), and `matrik/` (matrix exercises `no2` and `no3`) |

## Running the examples

```bash
g++ C++/no2.cpp -o no2 && ./no2
php PHP/no2.php
python Python/kabisat.py
```
