# C++ basics

| Folder or file | What it covers |
|---|---|
| `basics/` | Input and output, perimeter and area of shapes, conditionals (`percabangan`), and loops (`perulangan`, `looping`) |
| `basics/study-pakali/` | Class exercises, including 2D arrays |
| `basics/studycase/` | Small case-study programs |

## Running the examples

Compiled `.exe` files are not committed. Compile a file with g++:

```bash
g++ basics/perulangan.cpp -o perulangan
./perulangan
```
