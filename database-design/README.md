# Database design

Entity-relationship diagrams made with draw.io. Open the `.drawio` files at [app.diagrams.net](https://app.diagrams.net) or with the draw.io extension for VS Code.

| File | What it shows |
|---|---|
| `pharmacy-erd.drawio` | Pharmacy entities such as medicine, patient, prescription, cashier, supplier, and payment |
| `sales-erd.drawio` | A sales schema with customers, brands, and related entities |
| `sales-diagram.drawio` | An additional sales diagram |
| `production-erd.drawio` | A production diagram |
