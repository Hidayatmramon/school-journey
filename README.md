# School Journey (2020 to 2025)

Exercises and small projects from the years I spent learning to program, from the earliest repository I still have (2020) until I graduated from SMK Wikrama Bogor in 2025. SMK (*Sekolah Menengah Kejuruan*) is a vocational high school in Indonesia, and I majored in Software and Game Development. This repository shows how I moved from PHP and C++ basics to REST APIs, Vue, Flutter, and full web applications.

> **Looking for my finished work?** Start with the featured projects below. This repository is the learning history behind them.

## How to read this repository

- Each folder has its own README with what I practiced and how to run it.
- The code is kept close to how I wrote it at the time, so it favors learning over best practices. Known limitations are listed in the folder READMEs.
- My study notes in `php/php-basics/NOTES.md` and `php/oop-basics/NOTES.md` are written in Indonesian.
